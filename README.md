# 🐍 Exercícios de Raciocínio Algorítmico

Repositório dedicado aos exercícios desenvolvidos durante a disciplina de **Raciocínio Algorítmico** do curso de **Ciência da Computação na PUCPR**.

## 🎯 Objetivo

Desenvolver o raciocínio lógico e a capacidade de resolução de problemas através da implementação de algoritmos utilizando Python.

## 📚 Conteúdos Praticados

* Variáveis e Tipos de Dados
* Entrada e Saída de Dados
* Operadores Matemáticos e Lógicos
* Estruturas Condicionais (`if`, `elif`, `else`)
* Estruturas de Repetição (`for`, `while`)
* Funções
* Listas
* Matrizes
* Manipulação de Dados

## 💻 Linguagem Utilizada

![Python](https://img.shields.io/badge/Python-3776AB?style=for-the-badge&logo=python&logoColor=white)
          

## 🚀 Objetivos de Aprendizado

* Aprimorar o raciocínio lógico
* Desenvolver algoritmos eficientes
* Aprender os fundamentos da programação
* Aplicar conceitos estudados em aula
* Evoluir na resolução de problemas computacionais

## 📈 Evolução

Este repositório é atualizado conforme novos exercícios e atividades são desenvolvidos ao longo da disciplina.
